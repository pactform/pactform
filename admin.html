Repository settings & how to get a GitHub Token
  1. Open GitHub → Settings → Developer settings → Fine-grained tokens.
  2. Click Generate new token and select only the pactform/pactform repository.
  3. Under Repository permissions, set Contents to Read and write.
  4. Copy the generated token and paste it into the field above, then click Test Connection.
